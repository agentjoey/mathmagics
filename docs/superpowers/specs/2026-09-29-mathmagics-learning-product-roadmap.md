## 1. 决策与范围

用户明确否定了当前只有学习标题、状态和完成按钮的体验，并批准重新设计整体 scope。新产品承诺是：**提供实际可学的 Singapore Math 课程、可操作数学表示、随课 AI 辅导、有反馈的练习、作业订正及家长支持**。学习记录是教学过程的结果，不能代替教学过程。

首期仍以 P2/P3 家庭学习为范围，课程标准与教材版本分别管理。现有 curriculum graph 是对齐起点，不等于课程内容已经交付。Milestone A 的三个课例检验三个不同教学场景，不是把项目缩成三个 demo。

本文件替代旧 Phase 8 → 多周试点 → 再决定是否补教学内容的产品推进顺序。旧 Phase 1–8 的提交、迁移和测试仍是历史工程证据；它们不再证明儿童产品可用。已有 production activation 排查独立进行，本路线不追认其完成、不修改其授权，也不要求先完成部署才能做内容设计。

## 3. 产品体验

### 学生的系统学习

选择自己的头像后看到一项清楚的学习任务，进入已发布且有内容的课程。课堂围绕具体教具、例题与练习展开：看或听讲解 → 动手表示 → 引导作答 → 独立尝试 → 针对性帮助 → 新题检查 → 简短小结。随时能暂停并从原步骤恢复。完成活动与长期掌握分开报告。

### 学生的即时帮学

从一题、一页教材或一张作业照片发起求助。先确认系统读到了什么，再围绕同一内容讲解与订正；不强制先建立周计划。识别不清或不支持的题型显示待确认，不自动判错。

### 家长的教学支持

查看实际学了什么、独立完成了什么、使用了哪些帮助、哪里还需要支持，以及下一次建议。设置教材、学习位置、语言和可用时间。家长可提供说明，但不需要理解内部诊断枚举，也不必每一次都批准系统才能继续教。

## 4. 功能范围与交付边界

| 工作域 | 必须交付 | 不作为首版必要条件 |
|---|---|---|
| 课程内容 | 单元顺序、Lesson Pack、讲解、示范、练习、补救、退出检查及来源 | 自动生成整本长篇教材 |
| 互动课堂 | 内容播放器、数学教具、逐步推进、暂停恢复、朗读及文字替代 | 任意生成代码、复杂 3D 或视频制作平台 |
| AI Tutor | 理解当前步骤和作答，解释、追问、切换表示、选择许可的补救分支 | 通用多 Agent/MCP/CLI 市场 |
| 练习 | 模板变式、结构化答案、语义反馈、提示分层、专项练习 | 不受约束的现场出题和无依据自动打分 |
| 作业与错题 | 识别区域确认、逐题帮助、原题与订正关联、支持范围说明 | 承诺任意题型全自动批改 |
| 家长端 | 儿童选择、设置、可解释学习小结、具体辅导建议 | 学校班级运营和大型管理后台 |
| 内容制作 | 结构化创作、检查、课堂预览、版本和发布记录 | 大型 CMS、所有任务都要复杂审批 |
| 长期自适应 | 基于可靠作答的复习和补弱，教学记录可解释 | 在没有课程时先优化遗忘模型 |

权限、隐私、可访问性及失败恢复横跨这些工作域，不是末尾可选项。家庭内仍须验证学生归属；儿童不可自行修改家长设置、访问其他学生记录或调用开放工具。

## 5. 内容交付策略

知识点采用独立于教材的稳定 ID，教材按版本、册、章映射。公开目录只支持章节级映射，不代表已读完整教材或获准复制教材内容。课程脚本、题干、答案解释和教具设计原则上原创。

每个发布单元都有：目标与前置小检查、概念解释、至少一个完整示范、引导练习、独立检查、错误反馈、可暂停路径、家长说明和来源记录。数量随教学目标调整，不以固定题数替代教学设计。

题目供给优先使用审核过的锚定题与参数化模板。AI 可帮助生成情境与草稿，但数学结构、答案及语义约束经验证后才能进入课程。开放解释按明确 rubric 给建议；不确定反馈不能变成权威学习事实。

内容状态：`DRAFT → DESIGN_REVIEWED → IMPLEMENTED → PILOT_VALIDATED → PUBLISHED`。状态必须带证据；本次课例是 `DRAFT / ready for design review`。默认推荐只能返回 PUBLISHED 且渲染器、题目验证器均可用的课，缺内容不是给学生展示空页的理由。

## 6. Milestone A：产品设计与真实课例

交付：

1. 本路线与共用课堂/Lesson Pack 设计。
2. P2 按十和百数：从位值教具走到数列与跨百理解。
3. P2 等量分组与乘除：区分总数、组数、每组数量，以及两种除法情境。
4. P3 两步 Bar Model 应用题：先表示关系，再求未知量和总量。
5. 内容来源核查、设计验收与下一单元的连续课时骨架。

三份课例的教学脚本、题干、正确答案、提示、补救和恢复场景必须具体到不需要实施者重新编课。本阶段不实现播放器、不更换数据库、不改 Mastery、不部署。验收分为设计检查与后续实际试学，不能把两者混称通过。

入口：[Milestone A 交付包](../../milestone-a/README.md)。

## 7. Milestone B：第一条可连续学习的课程线

建议首条为 P2 数到 1000 的前段课程，复用 A1 的位值与数轴能力。以下是待实施设计的连续课时，不是已完成内容：

| 课时 | 实际教学目标 | 与前后课关系 |
|---|---|---|
| B1 | 用个位、十棒、百板表示数量 | 补齐 A1 所需表示基础 |
| B2 | 按十数，包含跨百 | A1 的十数段 |
| B3 | 按百数，比较加十与加百 | A1 的百数段；不要求 B2/B3 一次学完 |
| B4 | 把表示与数字、数词连接起来 | 对齐 P2-WN-002/003 的相应子技能 |
| B5 | 比较和排序；在数轴定位 | 对齐 P2-WN-004，数轴作为工具 |
| B6 | 识别和续写数列，综合检查 | 对齐 P2-WN-005；未包括整个 P2-WHOLE |

B 的交付还包括：Lesson Pack 加载与版本校验、课堂播放器、至少两种输入、可信数学表示、随课 Tutor、作答/帮助记录、恢复进度、家长小结、内容预览发布路径。

验收：连续课程均非空壳；可不依赖现场 LLM 完成基础讲解和作答；同一任务在暂停、重进、重复提交时不丢失或重复结算；模型失败不阻止教学；进行有知情同意的真实家庭试学。样本规模小，报告只能说明可用性观察，不能宣称学习效果已被统计证明。

开始 B 前仅需对 A 的课例与关键契约完成一次合并审阅，再形成可执行的 B 实施计划；不重复启动产品定位讨论，不按每个按钮设置审批点。

## 8. Milestone C：完整 P2/P3 与家庭日常使用

按 MOE 分域和教材版本建立逐目标覆盖矩阵，核实范围后逐单元发布：P2/P3 数与运算、分数、钱币、测量、时间、图形及数据。该列表是本项目范围索引；完整细目以经核实的 syllabus 和课程对齐记录为准。

每一目标单独记录：范围已核实、教学包、练习、补救、表示组件、浏览器验证、试学证据、发布状态。部分示例不代表整目标覆盖；支持生成题不代表能够教。

完善即时帮学、作业区域确认、错题关联、专项练习、家长设置与使用指导。图片保留策略按家庭设置和必要性决定；若选择持久保存，届时实现相应访问隔离、保留期和删除流程，不使用浏览器缓存代替权限。

C 验收不是总测试数，而是发布范围内所有目标均有可用内容和验证证据，缺口明确展示。教材章节与 MOE 学段并非机械一一对应，不能用书册目录直接改写课程标准。

## 9. Milestone D：长期复习与个性化

在可靠的教学与作答记录上优化间隔复习、跨单元补弱、教学节奏、语言和表示偏好。区分立即重复与延迟提取，保留向前学习的机会。不得把经验公式输出的遗忘概率包装成校准后的儿童能力结论。

## 10. 架构取舍

保留 Next.js/TypeScript 模块化单体与现有持久化作为优先方案。课程内容层、课堂会话层和 Tutor 接口是新工作重点；是否改写旧 service 由 B 实施计划逐项决定。

参考 DeepTutor 的 typed blocks、同页对话、校验后渲染和来源定位；不整体 fork，也不复制其成人工作台。具体参考及局限见 [sources](../../milestone-a/sources.md)。

**AI 可以有教学主动性，但不能获得任意修改权。** 在当前目标的许可范围内选择解释、表示和补救，与选择长期 curriculum 路径、更改答案、写 Mastery 是不同权限。后者仍由应用验证与管理。学习帮助无需先确定永久错误标签。

示范允许展示完整解法；独立检查答案留在服务端，主动请求解法后该次记为 assisted，再给新题验证。通过一次题卡或按完成按钮都不是整个 objective 已掌握的证明。

## 11. 风险、假设与停止条件

- 本次英语题干加中文教学脚本是可逆的设计基线，不是用户已指定的唯一语言。播放器需支持统一语言或按需翻译，不能默认同时塞满两种语言。朗读缺失时显示文字，语音输入不作为必需条件。
- 15–20 分钟仅作课例编排假设，不是标准时长；第二课分为可独立暂停的两段。不能据时长、点击次数或停留推断学会。
- 三个样本只提供局部子技能证据，不覆盖全表、全部三位数或所有两步应用题。
- 外部 syllabus 在线访问本次受限制；引用现有 repo 的 ID，并在发布前复核，不声称完成全量课纲审查。
- 不用现有生产库试内容，不改 production activation task。发现真实数据风险或需要迁移时另列明确方案。

## 12. 验收原则

工程检查、内容准确性、课堂可操作性、儿童试学四种证据分别记录。A 结束是设计包具备可审阅性，不是产品已上线；B 才实现可体验课堂，C 才完成全范围内容交付。旧 Phase 编号保留用于查历史，新工作统一使用 Milestone A–D。

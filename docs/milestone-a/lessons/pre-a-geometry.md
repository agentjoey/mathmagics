# A4 · 图形小侦探：AMC Pre-A 目标难度的几何拓展

Lesson ID：`A4-GEO-PREA`；版本：`design-1`；状态：DRAFT / ready for design review。
2026-09-29 用户要求将 AMC Pre-A 难度几何加入原课例包；A1–A3 保留。本课为原创内容，不是官方真题，也不是官方授权备赛课程。

## 1. 级别与难度依据

这里的 AMC 是 **Australian Mathematics Competition**。中国区组织方 [ASEEDER 的 AMC 页面](https://www.seedasdan.asia/amc/)明确将 Pre-A 对应小学一、二年级，2026 年中国区新增，25 题、50 分钟。AMT [官方页面](https://amt.edu.au/amc)另有面向 Years 1–2 的 Early Primary 试行安排；地区安排不互相替代，不能据此宣称两地试卷相同。

已核实级别、年级和选择/整数作答形式；本次查阅的公开页面未提供可逐题核验的 Pre-A 几何专项样卷或细分考纲。AMT 的公开样题入口从 Middle Primary 开始，不能冒充 Pre-A 样题。本课标记为 **“Pre-A 目标难度，待样题校准”**，不宣称已证明与正式试卷等难。

设计基线：短句读题、图形为主、计数在 20 内、每次一至两步空间推理。难度来自观察、旋转匹配和有序计数，不靠高年级公式。Foundation/Core/Stretch 是本产品内部分层，不是官方题号或分数段。

| 层级 | 本课任务 | 支持方式 |
|---|---|---|
| Foundation | 图形转向后的识别、找边和角、跟随转动 | 可操作教具与完整示范 |
| Core | 旋转匹配、无重叠拼合、按大小数正方形 | 先引导再独立，可求助 |
| Stretch（可选） | 排除同面积镜像干扰；缺角网格的复合计数 | 自愿挑战，可返回 Core，不影响主线进度 |

适配 P2 拓展及 P3 的基础几何补充，不修改参赛年级规则。与现有 `P2-2D-001` 的图形/方向模式有局部关联；拼合与复合计数为 ENRICHMENT，**不改变核心课程 Mastery**。不把本课通过写成 P3 角度或面积单元已掌握。

本课不包含角度数值运算、面积/周长公式、圆周率、相似比例、复杂折纸或立方体展开图。轴对称和立体观察可另做几何包，不能在本样本中虚报覆盖。

## 2. 课时、输入与数学图示

三段可暂停短课，建议各 5–8 分钟，仅为待试学的编排假设：A4a 认图与转动；A4b 拼合；A4c 有序数图。X1/X2 为可选挑战，不强制计时、不排名。

图形和作者答案见 [geometry fixtures](pre-a-geometry-fixtures.json)。它是设计数据，不是生产 schema；不可将含答案的作者包原样发到学生端。坐标仅给实施者，儿童不需要懂坐标系。

- 单位格等宽等高。`#` 为存在格，`.` 为不存在区域，不画外框；每个存在格的四条边均画实线，共用边合并，不画对角线。点号不是空白正方形。
- 拼片为整块硬卡片，所有选择项都是四个等大格子。允许平移、平面内转动；题面明确“不能翻到背面”。不可悄悄允许镜像。
- 旋转按钮每次顺时针四分之一圈；给儿童方向环“上→右→下→左→上”，不要求读 90°。初始朝向与次数要保留。
- 图形按顶点闭合，回到起点不多算一边。正方形转斜仍是正方形；不能教“四条边就一定是正方形”。
- 数所有大小、四边完整的正方形；不同位置可以重叠，同一边界只计一次。只能用实际画出的水平/竖直边，不想象缺失边。
- 点击、键盘和旋转按钮替代拖动；放大、朗读可用。不以手指拖不准判断数学错误，独立题不在悬停时自动提示正确位置。

建议可信组件：`SHAPE_OUTLINE`、`QUARTER_TURN`、`TILE_FIT`、`SQUARE_GRID`。模型可换解释，不能改顶点、格子、操作规则和答案。通用模式见 [课堂契约](../classroom-and-lesson-pack.md)。

微型补课：不会读“顺时针”先跟方向环走一圈；不会认边先在轮廓放起点标记；不会找大正方形使用 W2 外框。补课与示范不计独立成绩。每段都有结束点，不能强迫一次完成三段。

## 5. 可直接制作的图定义

真实页面每个 `#` 都是带四条实线边的单位格，共享边只画一次，不是一团无分隔的色块。

```text
W2       G2       I2       X2       R2
##       ###      ###      ###      ##.
##       ###      ##.      ###      ###
                           ##.      ##.
```

拼片作者名称及行模式如下；斜线只是分行符，不画进图。各行左端对齐，点号处没有格子。

| 名称 | 从上到下的行模式 |
|---|---|
| L | `#.` / `#.` / `##` |
| J | `.#` / `.#` / `##` |
| O | `##` / `##` |
| I | `####` |
| T | `###` / `.#.` |
| S | `.##` / `##.` |
| Z | `##.` / `.##` |
| LR | `###` / `#..` |
| JR | `###` / `..#` |
| SR | `#.` / `##` / `.#` |
| TR | `.#` / `##` / `.#` |

G3 目标 L：A=J / B=O / C=I / D=LR / E=T。
I3 目标 S：A=SR / B=Z / C=L / D=T / E=O。
X1 目标 J：A=L / B=T / C=JR / D=O / E=I。
R3 目标 T：A=L / B=J / C=O / D=I / E=TR。
W3 目标 L、演示片 LR，顺时针三次后贴合。

机器定义以 fixtures 为准；左上原点、x 右/y 下，每对整数是单位格左上角。拼合只允许平移与四种整四分之一圈旋转。每题恰好一个选项正确，不能放入两个旋转等价的正确选项。修改图形必须同时复核题干和答案。

## 6. 分层提示、完整解法和错误分支

| 题组 | H1 | H2 | H3 |
|---|---|---|---|
| PRE1/W1 | “沿外边绕一圈，回到起点停。” | 逐边点亮，比较转动前后 | PRE1 三条，W1 四条；转斜仍为正方形 |
| G1/I1/R1 | “先固定起点，再看往哪边转。” | 给方向环；I1 显示左→上，R1 显示右→下，各留最后一步 | G1 上→右→下→左；I1 左→上→右；R1 右→下→左 |
| W3/G3 | “看长条末端的小脚，不只数格子。” | 选长边再转整块，显示未贴合格，但不替学生选片 | LR 顺时针三次成 L；G3=D，A 是镜像不能只旋转得到 |
| I3 | “看两行错开的方向。” | 逐次转候选片，不允许翻面 | A=SR 顺时针一次成 S；三次也成立；B=Z 仅旋转不能成 S |
| X1/R3 | “盖完缺口，同时不盖到外面。” | X1 找 J 小脚；R3 找 T 中间伸出的格子 | X1=C，JR 顺时针一次成 J；R3=E，TR 顺时针三次成 T |
| W2/G2 | “先小的，再大的。” | W2 四小格再外圈；G2 移 2×2 框找两个位置 | W2 4+1=5；G2 6+2=8，没有 3×3 正方形 |
| I2 | “拿掉的格子不能补回来。” | 点五小格，检查两个 2×2 起点 | 左侧一个大正方形，5+1=6 |
| X2/R2 | “按大小，再从左到右检查位置。” | 移动 2×2 框，缺边的位置不计 | X2 8小+3大=11；R2 7小+2大=9；都无完整3×3 |

将 W1 叫“钻石”时：“它像钻石一样斜放，但它是刚才转过来的正方形。”不否定生活用语。G3 选 A 时先确认是否以为可以翻面，规则误读与空间错误分开。G2 答6时问“大的要一起数吗？”；答9时请指出多出的那个，不贴粗心标签。X2 答12时检查是否误数缺角外框。

其他错误先让学生指出起点、选片或已数边界，不从一个值推断永久错因。两次失败后提供示范/换种方式/暂停，避免循环逼答。看 H3 后可做对应 R 新题；不能追认原挑战为独立成功。

## 7. 难度校准和学习记录

识图、方向跟踪、刚性拼合、有序计数分别记录。朗读、放大和无障碍输入不等于数学提示；展示正确转动路径、未贴合位置或分类答案则是数学帮助。

X1/X2 未通过不阻塞主线、不降低原 Mastery。P3 学生可补基础，但不据年级自动换成 AMC A 或 AMC 8。

取得来源明确、有权使用的 Pre-A 样题后，按阅读量、基本概念、变换步数、元素密度和所需策略校准；儿童试学记录误读与帮助位置，再调整 Core/Stretch。在此之前不宣传真题同难、完整官方考纲覆盖或获奖概率。

家长模板：“完成{段落}；{任务}独立完成；{任务}借助{帮助}；下次建议{一项同类活动}。”没有作答就不生成能力结论。

## 8. 恢复和验收

恢复固定原 lesson/version、图实例、选择、旋转次数、平移位置、已数边界和帮助记录；不能恢复时自动摆出答案。提交幂等，无效拖放不算答错，切换学生清理草稿。

几何 QA 从顶点、格子、实际线段重新计算：旋转方向、正方形性质、大小封闭边界、四种旋转下唯一贴合，以及镜像/只按面积选择的反例。题目表与 fixtures 答案一致；A1–A3 的四则算式验证不能代替几何检查。

浏览器仍须检查缺格不残留实线、五个选项等比例、整片不形变、触屏/键盘等价、朗读不泄露答案、失败时固定内容可用。渲染失败时显示清楚的静态图或文字加纸片操作；文字替代不能等同宣称已验证视觉空间能力。

本次只交付课例、精确图形数据和作者侧验证；交互组件、音频、儿童试学未实施。A4 不自动扩大 B 的首条连续数数单元；几何为已纳入路线的独立后续教学包，不是被排除项。

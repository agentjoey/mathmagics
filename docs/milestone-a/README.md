## 已做的设计选择

第三类选用 Bar Model 应用题，覆盖 P3 和语言关系推理；分数模型仍属于整体 scope，不因未选作 A 的样本而删除。A2 用两段短课组织同一个设计样本，避免一次塞入全套乘除法。A1 同样允许在按十数之后暂停，不能把预计分钟数变成强制门槛。

每个题目有稳定 ID、教学用途、明确答案和帮助分支。设计文档包含教师端答案，未来学生端必须由服务端生成安全投影，不能原样发送本包。

## 设计验收与产品验收

本次设计检查核对课例数学关系、步骤、答案、提示、分支、来源与跨文件引用；后续产品验收还必须在真实页面和真实学习使用中完成。三份文档写完不等于 P2/P3 课程已完成，也不等于 Milestone B 获得自动实施批准。
